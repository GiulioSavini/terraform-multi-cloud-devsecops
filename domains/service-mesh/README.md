# Bounded context: service-mesh

Owns pod-to-pod mTLS and traffic policy: Linkerd and its trust anchor.

## Invariants

1. **Three control plane replicas in production.** Linkerd issues the
   certificates pods need to join the mesh; an outage stops new pods joining.
2. **The bundled Prometheus stays off when the observability context is
   present.** Two Prometheus instances scraping the same targets double the
   cost and disagree with each other during an incident, which is exactly when
   that matters.

## Trust anchor rotation

The trust anchor is generated by this context and expires. Rotation is a
two-step process — issue the new anchor alongside the old, restart workloads,
then remove the old — and is not automated here, because a single-step rotation
breaks mTLS for every pod that has not yet restarted.
